# Acuerdo de Nivel de Servicio (SLA) - EcoNode Serverless

Este SLA establece el compromiso de disponibilidad y rendimiento de la plataforma EcoNode Serverless de NexusLeaf Technologies S.L. hacia sus clientes.

## 1. Compromiso de Disponibilidad (Uptime)
NexusLeaf garantiza un tiempo de actividad mensual del **99.95%** para la disponibilidad de la API de enrutamiento de EcoNode.

## 2. Compromiso de Sostenibilidad (Green SLA)
Siendo una empresa enfocada en Green Ops, garantizamos que al menos el **95%** de los ciclos de cómputo del cliente serán ejecutados en centros de datos alimentados por energía 100% renovable (PUE < 1.15). En caso de no cumplir este compromiso mensual, el cliente recibirá créditos de carbono compensatorios.

## 3. Créditos por Incumplimiento
Si el Uptime mensual cae por debajo del 99.95%, el cliente tendrá derecho a recibir Créditos de Servicio según la siguiente tabla:

| Tiempo de Actividad Mensual | Porcentaje de Crédito |
| :--- | :--- |
| < 99.95% pero ≥ 99.0% | 10% de la facturación mensual |
| < 99.0% pero ≥ 95.0% | 25% de la facturación mensual |
| < 95.0% | 100% de la facturación mensual |

## 4. Exclusiones
Este SLA no se aplicará en casos de:
*   Mantenimientos programados anunciados con al menos 48 horas de antelación.
*   Cortes de red de proveedores troncales ajenos a NexusLeaf.
*   Uso indebido de la API o ataques de Denegación de Servicio (DDoS) generados por aplicaciones del cliente.
